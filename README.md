## 🚀 Quick Deployment Guide

You can deploy this portfolio online for **100% free** in less than 2 minutes using any of the options below:

### Option 1: Deploy with Netlify (Easiest - Drag & Drop)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this entire folder (`Paper Progress Resume`) into the upload area on Netlify.
3. Your site will instantly go live with a free custom URL (e.g. `posina-siva-sai-venkat.netlify.app`)!

---

### Option 2: Deploy with Vercel (CLI or Dashboard)
#### Via Vercel Dashboard:
1. Push this project folder to a repository on **GitHub**.
2. Log into [Vercel](https://vercel.com) and click **"Add New" -> "Project"**.
3. Import your GitHub repository and click **Deploy**.

#### Via Vercel CLI (Command Line):
```bash
npx vercel
```
Follow the prompts to launch your site in seconds!

---

### Option 3: Deploy with GitHub Pages
1. Initialize a Git repository inside this directory (if not done already):
   ```bash
   git init
   git add .
   git commit -m "Deploy sketch portfolio"
   ```
2. Create a new public repository named `portfolio` on [GitHub](https://github.com/new).
3. Push your code:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings -> Pages**.
5. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
6. Your portfolio will be live at `https://YOUR_USERNAME.github.io/portfolio/`.
